
# 快捷推送镜像

```shell
docker login -u codercl          # 步骤 1：登录（PAT 需 Read/Write/Delete 权限）
./scripts/push.sh 1.0.0          # 步骤 2：一键多架构构建并推送 <DOCKERHUB_USER>/blogloom:1.0.0 与 :latest
```

# 升级

```shell
/opt/server/blogloom

cd blogloom
./upgrade.sh            # 自动解析最新版本并升级
./upgrade.sh 1.0.1      # 升级到指定版本
```
