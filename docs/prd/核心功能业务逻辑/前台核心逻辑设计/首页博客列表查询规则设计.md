# 首页博客列表查询规则设计

> 文档类型：产品功能规则（PRD）
> 适用模块：博客前台 · 首页
> 适用版本：`release_1.0.x`
> 更新日期：2026-09-19

---

## 一、功能目标

首页是访客进入站点的第一屏。本规则定义首页博客列表在**默认进入**与**使用筛选标签**两种情形下的查询与排序逻辑，保证：

- 打开首页即可看到「置顶优先、最近更新靠前」的内容；
- 访客可按「置顶文章 / 按发布时间 / 按访问量」快速切换视角；
- 筛选可反复选中与取消，取消后回到默认视图，交互简单可预期。

---

## 二、页面元素

首页顶部工具栏左侧为**筛选标签**，顺序固定为：

| 顺序 | 标签 | 图标 | 说明 |
| --- | --- | --- | --- |
| 1 | 置顶文章 | 图钉（pin） | 只看被置顶的文章 |
| 2 | 按发布时间 | 时钟 | 按文章创建时间排序 |
| 3 | 按访问量 | 火苗 | 按文章阅读量排序 |

- **默认进入首页时不选中任何标签**；
- 选中的标签呈高亮（激活）态。

---

## 三、查询规则

### 3.1 基础过滤（所有情形通用）

无论是否选中筛选标签，列表只返回：

- **已公开**的文章（私密、密码保护文章不进入首页列表）；
- **未删除**的文章（回收站中的文章不展示）。

### 3.2 默认查询（未选中任何标签）

进入首页、或取消全部筛选后，使用默认规则：

> **排序：置顶优先前置，其次更新时间靠前。**

即：先按是否置顶倒序（置顶在前），置顶与非置顶内部均按更新时间倒序（最近更新在前）。

### 3.3 选中查询

| 选中标签 | 过滤条件 | 排序规则 |
| --- | --- | --- |
| 置顶文章 | 仅置顶文章 | 置顶优先，其次更新时间靠前 |
| 按发布时间 | 全部公开文章 | 置顶优先，其次创建时间靠前 |
| 按访问量 | 全部公开文章 | 置顶优先，其次访问量从高到低，再按创建时间靠前 |

> 说明：「按发布时间 / 按访问量」仍保持置顶文章前置，符合博客站点的通用展示习惯。

### 3.4 选中与取消（Toggle）

- 点击**未选中**的标签 → 选中并按该标签规则查询；
- **再次点击已选中**的标签 → **取消选中**，回到「默认查询」规则；
- 三个标签之间互斥，任意时刻最多选中一个。

---

## 四、分页规则

| 项 | 规则 |
| --- | --- |
| 每页数量 | 默认 **15 篇/页** |
| 翻页 | 底部显示分页控件，可切换页码 |
| 单页隐藏 | 当只有 1 页时，分页控件自动隐藏 |
| 切换筛选 | 切换或取消筛选后，**回到第 1 页**重新加载 |
| 排序一致性 | 翻页时沿用当前筛选/排序规则 |

---

## 五、列表展示内容

每条文章展示：封面图、标题、文章描述、发布时间、阅读量、所属分类、标签、阅读时长。

---

## 六、交互细则

1. **筛选与搜索相互独立**：使用顶部搜索框进入搜索结果态；点击筛选标签会退出搜索结果并回到列表态。
2. **空状态**：当前筛选下没有文章时，展示友好的空状态提示（如「这里还没有文章」）与「刷新看看」。
3. **排序稳定性**：同一排序下，多篇文章时间/访问量相同的情况下，保证顺序稳定、不跳动。
4. **数据实时性**：访问量以实时统计为准，展示在列表元信息中。

---

## 七、边界与异常

| 场景 | 处理 |
| --- | --- |
| 首页无任何公开文章 | 展示空状态，不报错 |
| 选中「置顶文章」但无置顶文章 | 展示空状态 |
| 排序字段值缺失（如无阅读量） | 按 0 处理，不影响其它文章排序 |
| 页码超出范围 | 返回空列表，前端保持当前筛选 |

---

## 八、验收标准

1. 首次进入首页，**无任何标签被选中**，列表按「置顶优先 → 更新时间靠前」展示；
2. 点击「置顶文章」，列表只出现置顶文章，且置顶内按更新时间倒序；
3. 点击「按发布时间」，列表按创建时间倒序（置顶仍前置）；
4. 点击「按访问量」，列表按访问量从高到低（置顶仍前置）；
5. **再次点击已选中的标签可取消选中**，列表回到默认规则；
6. 任意筛选下每页 15 篇，可正常翻页；切换筛选后回到第 1 页；
7. 私密/密码保护文章与回收站文章不出现在首页列表；
8. 无内容时展示空状态，不出现报错。
