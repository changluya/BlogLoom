## 一、产品简介

BlogLoom 博客前台是站点的内容门户，把站长创作的文章、动态、专栏等内容，以清晰、好读、易检索的方式呈现给读者。

一句话概括：**让内容被看见、被找到、被喜欢。**

## 二、功能结构总览

博客前台由 5 个功能模块组成，各模块下的功能如下：

| 功能模块 | 包含功能 |
| --- | --- |
| 内容浏览 | 首页、分类浏览、标签浏览、专栏阅读、归档回顾、站内搜索 |
| 阅读体验 | 文章阅读、目录定位、代码高亮与图片预览、密码阅读、专注模式 |
| 互动交流 | 评论与回复、动态点赞、赞赏 |
| 站点信息 | 个人名片、关于我、友人帐 |
| 全端适配 | 电脑 / 平板 / 手机自适应 |

## 三、内容浏览

提供多种找到内容的入口，让读者无论按时间、主题还是关键词，都能快速定位想看的文章。

### 3.1 首页
默认按「最新发布」展示文章列表，也可切换为「按访问量」查看热门。每篇文章展示封面、标题、摘要、发布时间、阅读量、分类与标签，帮助读者快速判断是否值得一读。

### 3.2 分类浏览
分类是文章稳定的栏目划分，读者可通过导航或文章内的分类入口，集中查看某一类别的全部文章。

### 3.3 标签浏览
标签是文章的主题标记，适合跨栏目检索同主题内容，点击任意标签即可查看相关文章。

### 3.4 专栏阅读
专栏把系列文章聚合成一条阅读线（如教程、更新日志），读者可在侧栏「TA 的专栏」进入，连续阅读系列内容。

### 3.5 归档回顾
归档按时间线组织全部公开文章，按年月分组，适合回顾历史内容。

### 3.6 站内搜索
顶部提供搜索框，输入关键词即可检索全站文章，并展示包含关键词的摘要片段；没有匹配结果时也会有清晰提示。

## 四、阅读体验

让读者舒适地读完一篇文章，并提供多种阅读辅助。

### 4.1 文章阅读
文章详情页完整呈现内容，支持标题、列表、表格、引用、图片等常见排版，并展示发布时间、分类、标签、阅读量与阅读时长等信息。

### 4.2 目录定位
文章较长时自动生成目录，点击即可跳转到对应章节，滚动时高亮当前所在位置。

### 4.3 代码高亮与图片预览
代码块带颜色高亮，便于阅读；正文图片可点击放大查看。

### 4.4 密码阅读
部分文章可设置访问密码，输入正确密码后即可阅读。

### 4.5 专注模式
一键隐藏两侧的推荐与名片，只保留正文，带来沉浸式阅读体验。

## 五、互动交流

让读者与站长、以及其他读者产生连接。

### 5.1 评论与回复
读者可在文章下留言，也可回复他人评论，形成讨论；评论较多时分页显示。

### 5.2 动态点赞
在「动态」页可查看站长发布的短内容（类似朋友圈），并为其点赞。

### 5.3 赞赏
对喜欢的文章，可通过文章内的赞赏入口给予支持。

## 六、站点信息

帮助读者了解站长与站点背景，建立信任与个人品牌。

### 6.1 个人名片
首页展示站长头像、昵称、站点统计（总访问量、原创数、总阅读量）与社交链接。

### 6.2 关于我
介绍站长与站点背景。

### 6.3 友人帐
展示站长的友情链接，方便读者与站长的朋友们互相串门。
