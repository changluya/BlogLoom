## 一、产品简介

BlogLoom 管理后台是打理个人博客的一站式工作台，把内容创作、内容整理、站点设置、图片存放、数据查看与系统维护集中在一起。

一句话概括：**一个人也能轻松运营一个内容站点。**

## 三、数据概览

登录后的首页，用卡片和图表汇总站点运营情况：访问次数与访客人数、文章与评论数量、分类与标签分布、访客来源地区，以及最近一段时间的访问变化，帮助站长了解内容表现。

## 四、内容创作

### 4.1 写文章
用 Markdown 撰写正文，支持实时预览与全屏写作；同时配置标题、文章描述、封面图、分类、标签、专栏，以及推荐、公开/私密/密码、置顶、评论与赞赏开关。正文中的图片可上传到图床，保存时自动整理。

### 4.2 发动态
发布简短的图文动态，类似发朋友圈，发布后读者可在前台看到并点赞。

## 五、内容管理

### 5.1 文章管理
集中查看与维护所有文章：按标题或分类检索、分页浏览，一键开关置顶与推荐，修改可见性（公开 / 私密 / 密码保护），编辑内容，或删除文章（删除后进入回收站）。

页面右上角提供「Skill 下载」：一键下载一份已内置当前账号地址与登录令牌的 AI 技能包，交给支持 Skill 的 AI 助手后，即可用自然语言把本地 Markdown 文章同步到博客（详见 6.4）。

### 5.2 分类与标签管理
分类用于稳定的栏目划分（一篇文章一个分类），标签用于主题标记（一篇文章可有多个）；均支持新增、重命名、排序与删除。

### 5.3 专栏管理
用专栏聚合系列文章：新建、编辑、上传封面、写简介，支持两级结构与拖动调整顺序，可设置是否在前台显示，并支持专栏的导入与导出。

### 5.4 动态管理
维护前台动态内容：新增、编辑、删除，支持配图。

### 5.5 评论管理
集中查看读者留言：按文章筛选、回复评论、删除不合适的评论。

### 5.6 回收站
内容安全的一道保险。删除的文章先进入回收站，前台与列表立即隐藏，但分类、标签、专栏、评论均保留，可随时恢复；确认不再需要时，再彻底删除（不可恢复）。支持单篇与批量操作。

## 六、迁移与整理

### 6.1 知识库目录
用目录树像整理电脑文件夹一样整理文章：新建目录、改名、拖动调整层级与顺序、批量删除，点击文档即可预览或编辑，文章多起来后结构一目了然。

### 6.2 迁移本地文章
把电脑里已有的 Markdown 文章一次性搬进博客：支持多层文件夹（文件夹会变成目录），也可只选若干个 Markdown 文件（此时按每篇文章里的知识库路径归档）；每篇文章开头用一段 JSON 声明标题、标签、分类、摘要、专栏、创建/更新时间与知识库路径，封面图在正文中用 `![coverImg](图片链接)` 标记（只认 `coverImg` 这个标记，普通图片不会当作封面）；导入时自动创建并关联不存在的标签、分类，专栏只匹配已存在的（含二级专栏），不会自动新建；导入的文章默认公开，并默认开启赞赏与评论；提供示例与说明、导入前预检、导入中进度，出错整体取消，不留半成品。

### 6.3 备份文章
把整站文章按目录结构打包下载到电脑，作为本地备份；需要时再用「迁移本地文章」导回来。

### 6.4 AI Skill 同步（用 AI 助手同步本地博客）
在「文章管理」页右上角点击「Skill 下载」，即可获得一份专属的 AI 技能包（内含当前账号的站点地址与登录令牌，开箱即用）。把技能包交给支持 Skill 的 AI 助手后，用一句自然语言就能完成本地博客与站点的同步，无需手动逐篇操作：

- **新增 / 批量导入**：把单篇或整个目录的 Markdown 导入博客，自动归入知识库目录、自动创建并关联标签与分类、匹配已存在的专栏；
- **智能同步**：同一篇文章已存在时自动走更新、不存在时走新增，重复执行不会产生重复文章；
- **修改已有文章**：同步本地新版正文，或单独修改标题、描述、分类、标签、专栏、可见性、置顶与推荐；
- **查询文章**：按标题搜索文章，查看详情，列出全部分类、标签与专栏。

技能包与页面「迁移本地文章」使用的是同一套导入能力，因此行为与后台操作完全一致；令牌过期后，重新下载一次即可刷新。

## 七、站点配置

### 7.1 站点设置
配置面向访客的站点信息：网站名称、网站图标、页脚二维码与文案、版权与备案、赞赏码、播放器歌单、侧栏资料卡（头像、昵称、社交链接、滚动个签）、页脚徽标，以及一个自定义展示模块（可填标题与内容，开启后在前台侧栏显示）。修改后前台同步展示。

### 7.2 友链管理
维护「友人帐」的朋友链接：新增、编辑、删除，配置名称、网址与头像。

### 7.3 关于我
维护前台的「关于我」页面内容。

### 7.4 图片存放
统一管理博客里的图片存放到哪里，目前支持「本地」与「阿里云 OSS」两种方式：本地开箱即用、无需填写参数；阿里云需填写访问密钥、存储空间名称、所属地域与存放路径。选中哪个方式，对应配置会高亮显示，切换后立即生效、无需重启。每种方式都提供「测试连通性」，真实地上传并删除一张图片，用来确认参数填写正确、能否正常读写，帮助站长在正式使用前先排除问题。

## 八、系统与安全

### 8.1 定时任务
查看与运行周期性工作（如数据同步），支持手动执行与查看历史记录。

### 8.2 日志管理
记录后台发生过的事：登录日志、操作日志、异常日志、访问日志与任务日志，便于安全审计与问题排查。

### 8.3 访客统计
查看访问次数、访客人数、访客来源地区与访问趋势，帮助了解网站热度。
