# BlogLoom v1.0.0 发布说明

> 本文件为 [GitHub Release v1.0.0](https://github.com/changluya/BlogLoom/releases/tag/v1.0.0) 的版本说明留档，内容与 `CHANGELOG.md` 的 v1.0.0 段落保持一致。

## 概述

BlogLoom 首个开源版本。基于 Spring Boot、MyBatis 与 Vue 的前后端分离博客平台，提供公开博客前台、内容管理后台与后端服务，覆盖 Markdown 创作、内容管理、站点配置、评论互动、访问统计与 Docker 一键部署。

## Added

- 完成 BlogLoom 首次开源提交：提供博客前台、内容管理后台与 Spring Boot 后端服务，覆盖 Markdown 创作与展示、分类标签、归档、评论与回复、动态、友链及关于页，以及站点配置、内容管理、图床配置、访客统计、日志中心和定时任务；支持 Spring Security + JWT 认证、MySQL 持久化、Quartz 调度、评论通知与本地及第三方存储上传，并提供初始化 SQL、部署脚本、配置示例与基础文档。
- 新增外置 `conf` 目录配置加载机制，支持从项目根目录或后端模块启动时自动定位配置、日志、静态资源和上传目录。
- 支持博客编辑器本地文件上传，新上传资源先写入 `${user.conf}/upload/tmp/`，文章保存或编辑时按 `blogId` 归档至 `${user.conf}/upload/blogs/{blogId}/`；同步支持扫描首图、Markdown 和 HTML 中的受管资源，自动重写访问 URL 并清理已归档的临时文件。
- 新增本地 Markdown 知识库管理：支持 ZIP 校验导入、内存级进度查询、目录与文档树展示、搜索、拖拽移动、重命名、递归及批量删除、单文档下载与知识库 ZIP 导出。
- 新增博客回收站（列表 / 恢复 / 彻底删除），并支持专栏导入归档与知识库文章元数据解析。
- 重构图床为「本地」与「阿里云 OSS」两种上传渠道，并支持真实上传 / 删除的连通性测试。
- 新增 Docker 一键部署与增量升级方案，并将 Redis 缓存迁移至 MySQL（`cache_entry` 表）。
- 新增 BlogLoom Skill：后台「文章管理」可下载专属 AI 技能包，用自然语言完成本地 Markdown 文章的导入、更新与查询，行为与后台导入能力一致。
- 新增官网文档站（docs-website）及文档页面与导航校验 CI。

## Changed

- 完成 NBlog 到 BlogLoom 的项目品牌化重构（统一后端 Java 包名、应用入口、数据库脚本、前后台标识及项目配置），并重构博客前台与管理后台整体布局，更新首页 Banner、侧边栏、导航、仪表盘、登录页和品牌素材。
- 优化前台导航、文章卡片、侧边栏、页脚及响应式布局，完善搜索和“阅读全文”交互；将运行配置、Logback、上传和静态资源目录收口至 `conf` 目录，整理全量 SQL 及默认站点数据，并重写项目 README。
- 优化文章详情页的标题、元信息、正文、版权和评论区样式，新增加载状态、入场动画与移动端适配；统一路由滚动策略。
- 更新 BlogLoom 项目 Logo。
- 重构文章编辑发布流程与全屏编辑体验；优化博客详情作者资料卡并增加累计 PV、公开博客数与公开文章总阅读量统计；同步规范初始化及增量 SQL 目录，新增本地数据库快速升级脚本与部署配置。
- 优化整体 UI 布局与首页博客搜索右侧栏目数据统计，支持移动端样式对接。
- 仪表盘分类 / 标签统计改为 SQL 聚合，增强知识库导入会话与首页展示。
- 移除历史 GitHub / 又拍云 / 腾讯云图床代码与依赖。
- 收紧文章封面图识别规则：仅识别正文中 alt 为 `coverImg` 的图片，普通图片不再作为封面。

## Fixed

- 补充 MySQL `allowPublicKeyRetrieval` 连接参数，改善默认配置下的数据库连接兼容性。

```bash
mkdir blogloom && cd blogloom
curl -fsSL https://raw.githubusercontent.com/changluya/BlogLoom/master/docker/standalone/install.sh | bash
```

完整说明见 [README](./README.md) 与 [docker/README.md](./docker/README.md)。
