### 博客文章目录
**每篇博客的顶部都需要有如下的一个代码块：**

```shell
固定专栏结构：
要求：
  1. 标签（多个）：提取3-5个与文章内容高度相关的标签，确保覆盖核心主题，逗号隔开，可多个【优先已带的，如果没有则可增加补充添加】。   
  2、分类（一个）：提取不超过3个的文章内容高频所属分类，确保覆盖核心主题，逗号隔开，可多个【优先已带的，如果没有则可增加补充添加】；
  3. 摘要内容：150字以内，精炼总结文章核心内容，包含关键词以提升SEO效果，语言流畅且易于检索。  
样例输出（供参考，title是标题默认为""即可，tags为标签，categories为分类，tags和categories都是用,隔开，articleSummary为摘要内容，请直接根据实际博客内容填充，确保信息准确且符合SEO要求）
  4、专栏（多个）：column字段，划分文章内容为对应所关联的所属专栏中。
  5、createTime（创建时间）：文章首次创建的时间，固定格式 YYYY-MM-DD HH:mm:ss。
  6、updateTime（更新时间）：文章最近一次修改的时间，固定格式 YYYY-MM-DD HH:mm:ss。
  7、knowledgeBasePath：知识库路径字段，用于指定文章所属的知识库文件夹路径，格式如 /a/bb/cc，建议以 / 开头且末尾不带 /


要求每篇文章在最顶部有这个代码块包裹即可：
```JSON
{
   "title": "SqlParser解析器快速入门",
   "tags": "AI技术,SEO优化,内容营销",

   "createTime": "2026-09-19 14:30:00",

}

**导入到blogloom平台的一键导入知识库的时候额外规则：**

1）文章首图为**默认文章内容里的第一个链接图片**。

2）文章里的标签、分类，如果**数据库没有的则主动创建后然后进行关联**。

3）标题就是title，articleSummary对应就是**文章描述**即可。

4）column为所属专栏，同时文章里有**特定关联专栏，则需要新创建一个专栏（如果没有的话）**。

5）默认知识库导入就是**公开**

6）对于该篇博客的创建事件、编辑事件根据json段里的**createTime、updateTime**。

7）对应所在知识库的**目录结构位置跟参数knowledgeBasePath**走，表示对应文章所在的文件夹结构目录路径。

+ 平台导入知识库：则根着知识库结构走。
+ 平台单独导入博客文档情况：则根据着knowledgeBasePath走，如果为空则默认在知识库的根目录下。【适合增量本地构建文档之后同步到平台上】

8）封面图的识别为：**博客文章里带有![coverImg](**[**https://pictured-bed.oss-cn-beijing.aliyuncs.com/img/2024/202609212201801.png**](https://pictured-bed.oss-cn-beijing.aliyuncs.com/img/2024/202609212201801.png)**) **其中coverImg就表示封面图含义，如果没有则无封面图。

+ 所属位置：**建议是在顶部代码块code 与 # 一级或者## 二级标题中间部分。**
