# 功能开发
通常实际场景我们都是进行本地维护自己的博客，针对正式发布的博客，我自己个人是如下进行维护的：

<img src="https://cdn.nlark.com/yuque/0/2026/png/2464036/1789999524382-6eb40748-a4a8-4ba5-b7c8-cb70b2eb6952.png" width="408" alt="" title="" crop="0,0,1,1" id="uad88d6ee" class="ne-image">

**通常我们写完博客之后还需要去同步到平台上，那么如何进行加速同步呢？**

**我们希望直接提供一个skill，利用这个skill，可以实现快速将本地的博客同步到平台上：**

**1、实现blogloom skill**

**skills能力初步支持场景如下：**

+ 本地快速新增博客（对接平台导入博客完全快速本地同步）【页面导入博客逻辑接口】
+ 本地修改博客，直接来支持对应的博客完成博客内容以及相应参数的修改【页面编辑博客接口场景】

**2、skill支持可以直接在页面上下载（skill包中直接带有当前的用户token）**

支持后台cms系统-博客管理/文章管理右上角支持直接快速**下载skills**，然后可以快速进行直接对接使用。



# 支持场景如下
| 场景 | 快捷提示语 |
| --- | --- |
| 单篇导入 | 「把 `/Users/me/blogs/maven.md` 这篇导入到博客」 |
| 批量导入目录 | 「把这个目录下的所有博客同步到平台：`/Users/me/blogs/Java`」 |
| 目录归位导入 | 「把这篇文章导入到知识库的 `SqlParser` 目录下」 |
| 断点续传/避免重复 | 「这个目录导入时遇到同名的就跳过」 |
| 同步更新 | 「`maven.md` 我改过了，把它同步更新到线上」 |
| 搜索文章 | 「帮我找一下平台上标题带 `Maven` 的文章」 |
| 查看详情 | 「看一下 id 为 11 的文章详情」 |
| 改可见性 | 「把文章 11 设为私密」 |
| 置顶/推荐 | 「把文章 11 置顶」「把文章 11 设为推荐」 |
| 换专栏 | 「把文章 11 的专栏改成 `Maven&Gradle`」 |
| 对齐准备 | 「列出所有专栏和分类，我导入前确认下」 |
| 综合排查 | 「查一下文章 11 的标签和专栏，然后补上缺失的」 |
