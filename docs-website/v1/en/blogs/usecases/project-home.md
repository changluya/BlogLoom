## Scenario

An open-source project needs a stable home for its overview, changelog and documentation, with a feedback channel.

## Approach

- **Content organization**: maintain series such as "Changelog" and "Docs" as columns.
- **Pages**: use the about page and custom pages for project information.
- **Interaction**: collect feedback and questions through comments.
- **Media**: store screenshots and images through media management (local or Aliyun OSS).

## Steps

1. Deploy following the [deployment overview](/v1/en/deploy/index).
2. Configure project info and friends in [Site settings](/v1/en/guide/admin/site).
3. Publish release notes via [Authoring](/v1/en/guide/admin/article-editor).
4. Configure screenshot storage in [Media](/v1/en/guide/admin/media).

## Outcome

Project overview, updates and feedback in one self-maintained site.
