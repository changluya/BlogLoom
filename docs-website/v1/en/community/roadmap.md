The following is the evolution plan for BlogLoom and does not represent the current release.

## Planned items

- [ ] Upgrade to a modern JDK and Spring Boot version
- [ ] Migrate the admin console to Vue 3, TypeScript and a modern component system
- [ ] Improve SEO, Sitemap and RSS
- [ ] Add SSR/SSG for the public blog
- [ ] Build a configurable theme and page system
- [ ] Support multi-site management
- [ ] Extend multi-channel publishing to CSDN, Juejin, cnblogs and more
- [ ] Improve unified media resource management
- [ ] Introduce AI-assisted writing, summaries and content organization
- [ ] Provide a Docker Compose one-click deployment

## Get involved

Suggestions or interest in claiming a roadmap item are welcome in Issues.
