---
title: "Moments and Likes"
description: Display of short-form moments and like interaction.
---

Moments are used to publish short, category-free content, similar to social media posts.

## Display

- The front end shows moments as a timeline.
- Supports images and text.
- Visible on the home page or a standalone page.

## Like interaction

- Visitors can like a moment.
- Like state and counts are recorded by the backend.
- Display behavior can be controlled via site config.

## Managing moments

Add, edit or delete moments under "Content → Moments" in the admin console. See [Content management](/v1/en/guide/admin/content).
