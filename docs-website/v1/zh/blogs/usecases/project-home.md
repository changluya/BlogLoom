## 场景

开源项目需要一个稳定的主页，用于发布项目介绍、更新日志与使用说明，并保留评论反馈入口。

## 方案

- **内容组织**：用专栏维护「更新日志」「使用文档」等系列。
- **页面配置**：通过关于页与自定义页面承载项目说明。
- **评论互动**：用评论收集使用反馈与问题。
- **媒体资源**：通过图床管理（本地或阿里云 OSS）统一存放截图与配图。

## 相关配置

1. 按[部署概览](/v1/zh/deploy/index)完成部署。
2. 在[站点设置](/v1/zh/guide/admin/site)中配置项目信息与友链。
3. 用[文章创作](/v1/zh/guide/admin/article-editor)发布版本说明。
4. 在[图床管理](/v1/zh/guide/admin/media)中配置截图存储。

## 效果

项目介绍、更新与反馈集中在同一个可自主维护的站点。
