BlogLoom 面向习惯用 Markdown 写作的开发者和创作者。你可以继续在本地维护文章，也可以在管理后台写作，再用知识库目录、批量迁移和 AI Skill 把内容整理并发布到博客。

## 在一个后台完成写作与发布

文章编辑器支持 Markdown、实时预览和全屏写作。发布时可设置标题、描述、封面、分类、标签和专栏，也可控制文章是否公开、是否需要密码、是否置顶或推荐，以及评论和赞赏入口是否开启。

图片可上传到当前配置的图床。文章保存后，内容和相关资源由博客统一管理。

## 用目录整理已有文章

知识库目录以树形结构组织文章，可创建目录、调整层级和顺序，并在后台预览或编辑文档。它适合把本地 Markdown 内容按主题归档，再逐步迁移到博客。

「迁移本地文章」支持选择多层文件夹，也支持只选择若干 Markdown 文件。导入时可以按文件夹结构归档，或读取文章元数据中的知识库路径；导入前会进行预检，导入过程会显示进度，发生错误时整体取消，不留下部分导入的数据。分类和标签可随文章一起创建并关联，封面通过正文中的 `![coverImg](图片链接)` 标记。

需要本地留档时，可以按现有目录结构备份整站文章，再通过迁移功能导回。

## 用 AI Skill 同步本地内容

在管理后台的文章管理页下载专属 AI Skill 后，支持该格式的 AI 助手可以按自然语言执行常见内容操作：

- 导入单篇文章或批量同步目录；
- 更新已有文章正文，或修改标题、描述、分类、标签、专栏和可见性等属性；
- 按标题查询文章，并查看分类、标签和专栏。

Skill 与后台迁移功能使用同一套导入能力。重复同步会更新已有内容，减少重复文章；技能包中的登录令牌过期后，可重新下载刷新。

## 适合持续写作的方式

本地 Markdown 文件仍然是可携带、可备份的内容源；博客后台负责内容组织、访问控制和公开展示。目录整理、批量导入、备份与 AI 同步组成一条从本地创作到站点发布的工作流。
