博客前台围绕读者的三个需求组织：找到感兴趣的内容、顺畅读完文章、与作者和其他读者交流。

## 按主题、系列或时间找到文章

首页可按最新发布或访问量浏览文章。读者也可以从分类和标签进入主题内容，通过专栏沿着系列文章连续阅读，或按年月回顾归档。站内搜索会展示匹配文章及关键词摘要，没有结果时也会给出明确提示。

文章列表展示封面、标题、摘要、发布时间、阅读量、分类和标签，帮助读者快速判断内容。

## 让长文更容易阅读

文章详情页支持常见 Markdown 排版，并展示文章信息和阅读时长。文章较长时会生成目录，读者可以跳转到章节；滚动阅读时，目录会标记当前章节。代码块带语法高亮，正文图片可以点击放大。

站长也可以为文章启用访问密码。专注模式会收起两侧推荐和名片，只保留正文区域。前台会随电脑、平板和手机屏幕调整布局。

## 在内容下方继续交流

读者可发表评论、回复其他评论；动态页提供短内容浏览与点赞，文章也可开启赞赏入口。侧栏的个人名片、社交链接、自定义展示模块，以及关于我和友人帐页面，为读者提供更多了解站点和作者的入口。
