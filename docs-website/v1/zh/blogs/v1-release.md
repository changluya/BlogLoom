BlogLoom 1.0 是项目的首个正式版本，基于 Naccl/NBlog 二次开发，完成品牌化、工程整理与界面体验优化。

## 本次范围

- **三端分离**：博客前台、管理后台与后端服务独立运行与构建。
- **内容闭环**：文章、分类、标签、专栏、动态与评论。
- **站点配置**：站名、头像、首页轮播、社交链接、友链与关于页。
- **运营数据**：PV、UV、内容数量、分类标签分布与访客地图。
- **图床管理**：本地上传与 GitHub、又拍云、腾讯云配置入口。
- **系统能力**：账号、定时任务与日志中心。

## 数据库脚本

- 全量脚本：`sql/increment/init.sql`
- 增量脚本：`sql/increment/1.0/`

## 升级说明

全新环境导入 `init.sql` 即可。已有环境请使用 `bin/local/upgrate-sql.sh` 应用增量脚本，并在升级前备份数据库。

## 已知事项

- 默认后台账号为 `admin` / `123456`，请首次登录后立即修改。
- 前端展示可能受 Redis 缓存影响，修改数据后按需清理缓存。
