---
title: "邮件通知"
description: 配置评论邮件通知。
---

启用邮件通知后，新的评论可通过邮件提醒站长或相关访客。

## 配置项

| 配置 | 说明 |
| --- | --- |
| 发件服务器 | SMTP 服务器地址 |
| 端口 | SMTP 端口 |
| 账号 | 发件邮箱 |
| 授权码 | 邮箱授权码或密码 |
| 收件人 | 通知接收地址 |

## 使用方式

1. 在后端配置中填写邮件相关参数。
2. 在后台开启评论通知。
3. 发布测试评论验证是否收到邮件。

## 注意事项

- 使用邮箱授权码而非登录密码。
- 不要把授权码提交到版本库。
- 注意发送频率限制，避免被判定为垃圾邮件。
