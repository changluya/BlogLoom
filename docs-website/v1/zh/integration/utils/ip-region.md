BlogLoom 使用 ip2region 等能力解析访问 IP 的地域信息，用于访客地图与来源分析。

## 能力

- 解析 IP 对应的国家、省份与城市。
- 识别客户端与访问来源。
- 为数据仪表盘提供地域分布数据。

## 数据来源

- 访问记录由后端在请求处理时写入。
- 地域信息在统计时解析并聚合。
- 结合 `conf/logs/` 中的访问日志进行分析。

## 注意事项

- 反向代理场景需正确转发真实 IP（`X-Forwarded-For`）。
- 离线 IP 库需定期更新。
- 地域信息仅用于统计，注意隐私合规。
