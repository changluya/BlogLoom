通过 GitHub 仓库存储图片，适合希望将资源与代码一同版本化的场景。

## 配置项

- 仓库地址（`owner/repo`）
- 分支
- 访问令牌（Token）
- 自定义访问域名（可选）

## 使用方式

1. 在管理后台「图床管理」中选择 GitHub。
2. 填写仓库、分支与访问令牌。
3. 上传图片后，资源提交到指定仓库并返回访问地址。

## 注意事项

- 使用最小权限的访问令牌，避免使用账号密码。
- 令牌不要提交到版本库或写入前端代码。
- 仓库公开时图片可直接访问；私有仓库需要额外访问策略。
- 大文件较多时注意仓库体积与访问速度。
