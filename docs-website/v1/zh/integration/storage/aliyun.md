阿里云 OSS 图床将图片上传到阿里云对象存储，适合希望把资源与服务器解耦、借助云存储分发的场景。

## 配置项

- `accessKeyId`：阿里云访问密钥 ID
- `accessKeySecret`：阿里云访问密钥 Secret
- `bucket`：OSS Bucket 名称
- `area`：Bucket 所在地域（Endpoint 区域）
- `path`：存储路径前缀

## 使用方式

1. 在管理后台「图床管理」中选择阿里云 OSS。
2. 填写访问密钥、Bucket、地域与存储路径。
3. 使用「连通性测试」验证配置是否可用。
4. 上传图片后，资源写入指定 Bucket 并返回访问地址。

## 连通性测试

- 在图床管理中对已保存或正在填写的配置执行「连通性测试」。
- 后端会模拟上传一张探针图片并立即删除，确认密钥、Bucket 与地域可正常访问。
- 测试通过后即可放心切换为该图床。

## 注意事项

- 使用最小权限的访问密钥，避免使用主账号密钥。
- 密钥不要提交到版本库或写入前端代码。
- 注意 Bucket 的读写权限与跨域配置，确保前台可以访问图片。
- 大文件较多时注意存储费用与访问速度。
