---
title: "本地图床"
description: 将图片上传到服务器本地目录。
---

本地存储是默认的图床方式，图片保存在服务器文件系统中。

## 配置

- 上传目录默认为 `conf/upload/`。
- 通过 `conf/static/` 对外提供静态资源访问。
- 可在后台图床管理中查看与切换存储方式。

## 访问方式

- 上传后的图片通过配置的访问域名或路径访问。
- Nginx 可直接托管上传目录以提升性能。

## 注意事项

- 确保上传目录存在且具备写权限。
- 定期备份上传目录。
- 限制上传目录的可执行权限，避免安全问题。
- 注意磁盘空间，尤其是图片较多的站点。
