BlogLoom 的缓存由应用内部实现，使用 MySQL 表 `cache_entry` 保存缓存数据，不再依赖 Redis 等外部缓存服务。

## 实现方式

| 项目 | 说明 |
| --- | --- |
| 存储位置 | MySQL 表 `cache_entry` |
| 使用方式 | 由后端缓存模块读写，业务代码无感知 |
| 额外服务 | 无需部署 Redis 或其它缓存中间件 |

## 使用说明

- 缓存随数据库一起持久化，备份数据库即包含缓存数据。
- 站点配置等热点数据会被缓存，修改后按需清理缓存即可生效。
- 清理缓存不会影响文章、评论等业务数据。

## 运维建议

- 无需为缓存单独开放端口或配置密码。
- 随数据库一同监控表空间增长。
- 排查缓存相关问题时，检查数据库连接是否正常。
