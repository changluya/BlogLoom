description: 按症状定位常见问题。
---

## 后端无法启动

1. 查看启动日志中的异常堆栈。
2. 检查 MySQL 与 Redis 是否可连接。
3. 确认配置项完整、密钥已设置。
4. 确认端口 `8090` 未被占用。

## 前端页面空白或接口 404

1. 确认后端已启动。
2. 检查 `.env.production` 的 `VITE_API_URL`。
3. 检查 Nginx 反向代理与路由回退配置。

## 登录状态异常

1. 检查 Redis 是否正常。
2. 确认 `token.secretKey` 一致且未变更。
3. 清除浏览器本地存储后重试。

## 内容未更新

1. 确认数据库数据已更新。
2. 清理 Redis 缓存后刷新页面。
3. 检查浏览器与 CDN 缓存。

## 图片上传失败

1. 检查图床配置与凭据。
2. 检查本地上传目录权限与磁盘空间。
3. 查看后端日志中的上传异常。

## 收集信息

排查时优先收集：后端日志、浏览器控制台、接口响应与数据库状态。
