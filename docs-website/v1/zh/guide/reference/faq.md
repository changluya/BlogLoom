## 启动后端失败，提示数据库连接错误

检查 `application-dev.properties` 中的 MySQL 地址、用户名与密码，确认数据库已创建并导入 `init.sql`。

## 前端启动后接口报错

确认后端已启动在 `8090` 端口，并检查前端 `.env.development` 中的 `VITE_API_URL` 是否指向正确的后端地址。

## 登录后台提示账号或密码错误

默认账号为 `admin` / `123456`。若已修改密码，请使用新密码；忘记密码可通过数据库重置。

## 页面内容没有更新

前端展示可能同时受数据库站点配置和 Redis 缓存影响。修改初始化数据后，请同步数据库并按需清理缓存。

## 图片无法上传

检查图床配置是否完整，以及本地上传目录或第三方存储的凭据是否正确、权限是否充足。

## 评论没有邮件通知

确认已正确配置邮件服务，并检查授权码与发件服务器设置。

## 如何升级数据库

全新环境导入 `sql/increment/init.sql`；已有环境使用 `bin/local/upgrate-sql.sh` 应用增量脚本。
