系统管理覆盖后台账号安全与运行日志，是日常运维的重要入口。

## 账号管理

- 维护后台管理员账号与密码。
- 首次登录后请立即修改默认密码。
- 生产环境请使用足够长且随机的登录密钥。

## 定时任务

基于 Quartz 的定时任务用于周期性作业，可在后台查看执行状态与历史。

## 日志中心

| 日志类型 | 说明 |
| --- | --- |
| 任务日志 | 定时任务执行记录 |
| 登录日志 | 后台登录信息 |
| 操作日志 | 关键写操作记录 |
| 异常日志 | 系统异常堆栈 |
| 访问日志 | 访客访问记录 |

## 使用建议

- 通过操作日志追溯关键内容变更。
- 通过异常日志快速定位后端问题。
- 结合访问日志分析站点流量。
