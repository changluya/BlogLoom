站点设置用于维护面向访客的站点级内容，修改后前台会同步展示。

## 可配置项

- **基础信息**：网站名称、网站图标、头像、页脚二维码与文案、版权与备案
- **首页 Banner**：Banner 图片与跳转链接
- **社交链接**：GitHub、邮箱等外部链接
- **友链**：友链名称、地址与头像（友人帐）
- **关于我**：关于页内容
- **赞赏码**：文章赞赏入口
- **播放器歌单**：前台音乐播放器配置
- **自定义展示模块**：可填标题与内容，开启后在前台侧栏展示（可放公告、技术交流群、公众号等）

## 生效方式

- 前台读取后端返回的站点配置进行渲染。
- 部分配置会被缓存到内部 `cache_entry` 表，修改后可能需要清理缓存才能立即生效。

## 注意事项

- 修改初始化数据后，已运行环境需同步数据库并按需清理缓存。
- 图形与图片资源可通过图床管理统一上传。
