---
title: "数据仪表盘"
description: 站点内容与访问数据的运营概览。
---

登录管理后台后，首页即为数据仪表盘，集中展示站点运营概况。

## 展示内容

- PV / UV 访问量
- 文章、评论、分类与标签数量分布
- 最新评论与待处理内容
- 访客地图与地域分布

## 数据来源

- 访问数据由后端记录，结合 IP 地域解析生成访客分布。
- 内容数量实时从数据库统计。
- 图表使用 ECharts 渲染。

## 使用建议

- 通过访问趋势观察内容受欢迎程度。
- 结合分类标签分布调整内容规划。
- 关注异常波动，及时排查访问来源。
