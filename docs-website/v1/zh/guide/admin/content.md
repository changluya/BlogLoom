内容管理覆盖站点所有内容对象的日常维护。

## 管理对象

| 对象 | 可执行操作 |
| --- | --- |
| 文章 | 新增、编辑、发布、下架、删除 |
| 动态 | 新增、编辑、删除 |
| 分类 | 新增、重命名、排序、删除 |
| 标签 | 新增、重命名、删除 |
| 专栏 | 创建、调整结构、关联文章 |
| 评论 | 审核、回复、删除 |

## 内容组织建议

- 用分类做稳定的栏目划分，用标签做主题标记。
- 系列文章使用专栏聚合，便于读者连续阅读。
- 定期清理无效标签，保持检索清晰。
