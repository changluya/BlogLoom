内容管理覆盖站点所有内容对象的日常维护，是管理后台使用频率最高的模块。

## 管理对象

| 对象 | 可执行操作 |
| --- | --- |
| 文章 | 新增、编辑、发布、下架、删除（进入回收站） |
| 回收站 | 查看已删除文章，恢复或彻底删除，支持单篇与批量操作 |
| 动态 | 新增、编辑、删除，支持配图 |
| 分类 | 新增、重命名、排序、删除（一篇文章一个分类） |
| 标签 | 新增、重命名、删除（一篇文章可有多个） |
| 专栏 | 两级专栏管理，封面、简介、排序、导入导出与关联文章 |
| 本地知识库 | 目录树管理文章，ZIP 批量导入导出 |
| 评论 | 审核、回复、删除 |

## 内容组织建议

- 用分类做稳定的栏目划分，用标签做主题标记。
- 系列文章使用专栏聚合，便于读者连续阅读；专栏支持两级结构与封面、简介。
- 本地知识库可用目录树组织文章，通过 ZIP 批量导入导出，导入时自动解析标题、标签、分类、摘要、专栏、创建/更新时间与知识库路径等元数据；封面图在正文中用 `![coverImg](图片链接)` 标记（只认 `coverImg` 这个标记，普通图片不会当作封面）。
- 导入时标签、分类不存在会自动创建并关联，专栏只匹配已存在的（含二级专栏），不会自动新建。
- 文章删除后进入回收站，前台与列表立即隐藏，但分类、标签、专栏、评论均保留，可随时恢复。
- 文章管理页右上角提供「Skill 下载」，可交给 AI 助手用自然语言同步本地文章，详见 [AI Skill 同步](/v1/zh/integration/ai-skill)。

## 与 SEO 的关系

公开文章会进入 `sitemap.xml` 与 `rss.xml`，而草稿、回收站、密码保护文章不会；删除文章前请留意其对已收录内容的影响。
