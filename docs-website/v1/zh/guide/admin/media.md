title: "图床管理"
description: 上传配置与第三方对象存储的接入。
---

图床管理负责文章图片与站点资源的存储配置，支持本地与多种第三方存储。

## 支持的存储

| 存储 | 说明 |
| --- | --- |
| 本地 | 上传到服务器本地目录 |
| GitHub | 通过 GitHub 仓库存储图片 |
| 又拍云 | 又拍云对象存储 |
| 腾讯云 | 腾讯云对象存储 |

## 配置方式

在管理后台「图床管理」中选择存储方式并填写对应凭据，例如仓库地址、访问域名或对象存储密钥。

## 安全提示

- 请勿将对象存储密钥、访问令牌提交到版本库。
- 生产环境建议使用独立的存储桶与最小权限凭据。
- 定期检查上传目录的访问权限。
