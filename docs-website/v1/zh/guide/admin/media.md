图床管理负责文章图片与站点资源的存储配置，支持本地与阿里云 OSS 存储。

## 支持的存储

| 存储 | 说明 |
| --- | --- |
| 本地 | 上传到服务器本地目录，开箱即用、无需填写参数 |
| 阿里云 OSS | 上传到阿里云对象存储 |

## 配置方式

在管理后台「图床管理」中选择存储方式并填写对应凭据，例如访问密钥、存储空间名称、所属地域与存放路径；选中哪个方式，对应配置会高亮显示，切换后立即生效、无需重启。

每种方式都提供「连通性测试」：真实地上传并删除一张图片，用来确认参数填写正确、能否正常读写，帮助站长在正式使用前先排除问题。

## 安全提示

- 请勿将对象存储密钥、访问令牌提交到版本库。
- 生产环境建议使用独立的存储桶与最小权限凭据。
- 定期检查上传目录的访问权限。
