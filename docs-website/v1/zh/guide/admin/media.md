---

图床管理负责文章图片与站点资源的存储配置，支持本地与阿里云 OSS 存储。

## 支持的存储

| 存储 | 说明 |
| --- | --- |
| 本地 | 上传到服务器本地目录 |
| 阿里云 OSS | 上传到阿里云对象存储 |

## 配置方式

在管理后台「图床管理」中选择存储方式并填写对应凭据，例如 Bucket、地域、存储路径与访问密钥，并可执行「连通性测试」验证配置是否可用。

## 安全提示

- 请勿将对象存储密钥、访问令牌提交到版本库。
- 生产环境建议使用独立的存储桶与最小权限凭据。
- 定期检查上传目录的访问权限。
