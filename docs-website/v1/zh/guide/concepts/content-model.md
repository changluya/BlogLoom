BlogLoom 用一组相互关联的对象组织内容。理解这些对象，有助于正确配置前台与后台。

## 核心对象

| 对象 | 说明 | 关系 |
| --- | --- | --- |
| **文章（Blog）** | 一篇 Markdown 内容，是站点的核心实体 | 属于一个分类，可关联多个标签与专栏 |
| **分类（Category）** | 文章的一级归类 | 一篇文章属于一个分类 |
| **标签（Tag）** | 文章的主题标记 | 一篇文章可有多个标签 |
| **专栏（Column）** | 系列文章的集合，支持两级结构与封面、简介 | 与文章多对多关联 |
| **动态（Moment）** | 短内容，类似微博 | 支持点赞 |
| **评论（Comment）** | 文章下的访客互动 | 属于一篇文章，支持回复 |
| **页面配置（Site Setting）** | 站点级别的可配置内容 | 站名、头像、友链、关于页等 |

## 关系示意

```text
分类 (Category) 1 ──── * 文章 (Blog) * ──── * 标签 (Tag)
                              │
                              ├── * 评论 (Comment)
                              └── * 专栏 (Column)（多对多）
动态 (Moment) ── * 点赞
```

## 设计约定

- **一篇文章一个分类**：分类用于归档，标签用于主题检索。
- **专栏与文章多对多**：同一篇文章可以同时出现在多个专栏中。
- **评论支持嵌套**：通过父子关系实现回复。
- **动态独立于文章**：适合发布简短、无需分类的内容。
