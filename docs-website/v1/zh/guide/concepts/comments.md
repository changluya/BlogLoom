评论是博客与读者互动的核心。BlogLoom 的评论同时出现在前台与后台，并支持多种互动方式。

## 评论结构

- 评论归属于某篇文章。
- 评论支持回复，形成父子结构。
- 管理员可在后台审核、回复或删除评论。

## 互动能力

| 能力 | 说明 |
| --- | --- |
| 评论 | 访客在文章下发表评论 |
| 回复 | 对已有评论进行回复 |
| 动态点赞 | 对动态内容点赞 |
| 邮件通知 | 评论产生时通过邮件通知站长或访客 |

## 审核与安全

- 后台可查看全部评论并集中处理。
- 评论内容在展示前会做安全处理，避免脚本注入。
- 可结合邮件通知及时跟进新评论。

## 通知配置

评论邮件通知依赖邮件服务配置，详见[邮件通知](/v1/zh/integration/notification/email)。
