---

BlogLoom 提供多种检索入口，帮助访客按时间或主题找到内容。公开的分类、标签、专栏与归档页同样由后端服务端直出，便于搜索引擎收录。

## 浏览方式

| 入口 | 说明 |
| --- | --- |
| 分类 | 按文章分类聚合 |
| 标签 | 按主题标签聚合 |
| 归档 | 按时间线组织文章，按年月分组 |
| 专栏 | 按系列聚合文章（侧栏「TA 的专栏」） |

## 站内搜索

- 支持按关键词检索文章，并展示包含关键词的摘要片段。
- 搜索结果按相关度与时间排序。
- 搜索入口位于站点顶部导航。
- 没有匹配结果时会有清晰提示。

## 分页

列表页使用 PageHelper 在后端分页，前端按页加载，避免一次性返回大量数据。
