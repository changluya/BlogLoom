BlogLoom 提供多种检索入口，帮助访客按时间或主题找到内容。

## 浏览方式

| 入口 | 说明 |
| --- | --- |
| 分类 | 按文章分类聚合 |
| 标签 | 按主题标签聚合 |
| 归档 | 按时间线组织文章 |
| 专栏 | 按系列聚合文章 |

## 站内搜索

- 支持按关键词检索文章。
- 搜索结果按相关度与时间排序。
- 搜索入口位于站点导航。

## 分页

列表页使用 PageHelper 在后端分页，前端按页加载，避免一次性返回大量数据。
