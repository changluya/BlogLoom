
# 开发完某个分支后必做

## 1）本地更新文档（开发分支）

```shell
将本次分支功能同步补充到对应prd文档、仓库README.md、docs-website中，方便后续发布版本时进行文档更新
  prd文档（将核心功能 + 细节标准产品使用流程 规范进行按照之前格式来补充添加）：[产品功能文档-CMS系统.md](..%2Fdocs%2Fprd%2F%E4%BA%A7%E5%93%81%E5%8A%9F%E8%83%BD%E6%96%87%E6%A1%A3-CMS%E7%B3%BB%E7%BB%9F.md)BlogLoom/docs/prd/产品功能文档-CMS系统.md、[产品功能文档-博客前台.md](..%2Fdocs%2Fprd%2F%E4%BA%A7%E5%93%81%E5%8A%9F%E8%83%BD%E6%96%87%E6%A1%A3-%E5%8D%9A%E5%AE%A2%E5%89%8D%E5%8F%B0.md)
  仓库README.md（将核心功能添加，要求精炼）：[README.md](..%2FREADME.md)
  docs-website（将重要用户使用功能同步）：[docs-website](..%2Fdocs-website) 
```

## 2）快速推送代码提交合并

```shell
将当前分支合并到release_1.0 进行推送代码，然后将release_1.0分支合并到master分支进行推送代码
```

# 产品tag & docker镜像维护

## 产品tag维护

```shell
更新下近期的changelog，归属到当前最新tag中
```

## docker镜像tag

```shell
# 强制打包镜像推送
根据用户的说明来进行本地快速构建打包，推送覆盖镜像到当前最新tag，阅读下 [README.md](..%2Fdocker%2FREADME.md) 来完成镜像推送

# 快速打包发布(新tag)
镜像tag追加新增，完成构建打包推送tag 阅读下 [README.md](..%2Fdocker%2FREADME.md) 来完成镜像推送
```
